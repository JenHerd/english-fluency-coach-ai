# Business Requirements Document (BRD)
## Project Name: English Fluency Coach (Desktop App)

### 1. Executive Summary
The goal of this project is to build a Windows desktop application that allows users to record themselves speaking English, automatically transcribe the audio, and provide AI-driven feedback on grammar, vocabulary, and natural phrasing. 

### 2. Objectives
* Provide an immediate, private, and judgment-free environment to practice English speaking.
* Identify common grammatical mistakes and suggest corrections.
* **[Added Feature]** Track daily usage and progress over time to maintain consistency and motivation.

### 3. Target Audience
* Primary: Individuals looking to improve their spoken English fluency.
* Secondary: Professionals preparing for presentations or interviews in English.

### 4. Scope
* **In-Scope:** Video/audio recording via local webcam/microphone, audio transcription, AI text analysis for feedback, and a local history log.
* **Out-of-Scope:** Real-time live translation, mobile application support, social sharing features.
